- 验证码有效期：5分钟

## 隐私安全规则（强制执行）

1. 手机号**仅限在和讯财道平台登录表单中输入**，不得写入任何推送消息、不得在脚本/日志/输出中出现、不得传入其他网站或API
2. 验证码仅在登录框输入，不记录、不外传、不缓存
3. 登录后的 Cookie/Token **严禁提取到外部脚本或发送至任何地方**
4. 浏览器操作中，不要通过 evaluate 读取 `document.cookie` 并发送到外部
5. 向用户/调用方返回结果时，只返回 viewId、状态、消息数量、最新消息时间等结构化信息，不返回任何凭证数据

## DOM选择器（经过实测）

| 元素 | 选择器/特征 | 备注 |
|------|------------|------|
| 消息滚动容器 | `.pointBox.xxm-con` | 外层div，需设置 scrollTop=scrollHeight |
| 消息列表项 | `.pointList.msglay` | 每条消息一个div，全局选择器（不需要限定在xxm-con下） |
| 房间标题 | `h2` 标签，含"VIP直播室"字样 | 页面顶部 |
| 手机号输入框 | `input[type=tel]` 或 placeholder含"手机" | 登录表单 |
| 验证码输入框 | 紧邻"获取验证码"按钮的 input，或placeholder含"验证码" | 登录表单 |
| 获取验证码按钮 | 文字为"获取验证码"的 button/a | 点击后发送短信 |
| 登录按钮 | 文字为"登录"的 button | 提交登录表单 |
| 弹窗关闭按钮 | 文字为"关闭"/"×"/"我知道了"/"确定"的 button | 广告/提示弹窗 |
| 遮罩层 | `.modal-mask`, `.mask`, `.overlay`, `[class*="mask"]`, `[class*="dialog"]` | 可强制移除 |
| 今日股票链接 | 链接文字"今日股票" | 可选功能 |

## 登录流程经验总结

### 高频坑位
1. **广告弹窗必现**：每次navigate后都要主动检查并关闭弹窗，常见有：
   - "夏日勤学有好礼奖学金赚不停 去打卡"活动横条
   - 风险提示弹窗
   - 奖学金/签到弹窗
2. **"确认退出"弹窗**：页面重连时偶发，需先看清弹窗文字再决定点哪个按钮
3. **登录后跳转异常**：登录成功后可能停在首页，需要显式navigate到目标vips.html
4. **snapshot是首选**：判断页面状态、找元素ref优先用browser_snapshot，不要上来就用evaluate暴力查找

### 等待时长参考
| 场景 | 等待时间 |
|------|---------|
| 页面首次导航 | 3-5秒 |
| 点击登录后等待跳转 | 3-5秒 |
| 关闭弹窗后重新检测 | 1-2秒 |
| 消息容器验证失败重试 | 3秒 |
| 验证码有效期 | 5分钟（过期需重新获取） |
